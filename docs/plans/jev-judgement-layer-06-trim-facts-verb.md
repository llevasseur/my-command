# jev-judgement-layer-06 — The deterministic trim gates verb

**Wayfinder:** `jev-judgement-layer`
**Branch:** `task/jev-judgement-layer-06-trim-facts-verb`
**Status:** done · 2026-09-17

No predecessors, and no dependency on the client or the question sets. **Runs in the
first wave, in parallel with 01 and 03.**

## Why this exists

[ADR 0007](../adrs/0007-deterministic-trim-gates-stay-a-facts-verb.md) removed four of
`/trim`'s six gates from the judgement layer. They are facts, and
[Command toolkit](../specs/command-toolkit.md) already states the rule — "Judgment stays
with the agent. The toolkit never decides whether a comment is noise" — paired with the
layering that gives a repeated deterministic derivation a verb printing JSON.

Routing a boolean that cannot be wrong through a classifier that can adds a network round
trip, a confidence band, and a failure mode to a computation that has none.

## Criteria

A verb answering these four, from the machinery `src/hooks/lib/` already runs for the
gates — `timeline()`, `read-only.mjs`, `watchedOutputs()` — plus `my-command-tools state`:

- **C1 CLOSED**, returned-calls half — the last turn's calls all returned, none came back
  `is_error`, and no `Monitor` or backgrounded Bash call is still live.
- **C3 PROGRESS** — turns since the last compaction boundary carrying a call that is not
  read-only, plus `hasWork` and `diffStat` from `state`.
- **N1 STUCK**, arithmetic half — the repeat-identical-probe and repeat-error counts the
  existing gates already derive.
- **N2 LIVE** — an unreturned `Agent` dispatch, a live watch, or an unmerged path from
  `git diff --diff-filter=U`.

**Report the two residual gates as `unknown` rather than guessing.** C2 RECOVERABLE and
N3 VERIFIED — along with C1's "mid-tool sequence" clause and N1's "would hide useful
negative evidence" clause — are not answerable here. They belong to ticket 03's question
set. A verb that returned a confident boolean for them would be the failure this ADR
exists to prevent, in the opposite direction.

**Widen `/trim`'s `allowed-tools`.** It currently reads
`Read, Grep, Glob, Bash(git:*)` and therefore cannot call the toolkit at all. Add
`Bash(my-command-tools:*)`, which is the form [Command toolkit](../specs/command-toolkit.md)
says a command declares so the bare call resolves.

**`timeline()` must stay one implementation.** The hooks read the transcript to refuse a
call; this verb reads it to report state. They share `src/hooks/lib/`, so **import it
rather than reimplementing it**. [Command toolkit](../specs/command-toolkit.md) makes the
same argument for hook-arming detection: "One detector, not two."

## Constraints

- **No key, no network call, no fail-open path.** A computation that cannot be wrong has
  nothing to fail open from.
- This verb is useful whether or not the judgement layer ever ships, which is why it has
  no dependency on any other ticket here.
- `src/commands/` is the source; `commands/` is generated by `./scripts/build-plugin.sh`
  and **never hand-edited**. Regenerate it after the `trim.md` edit.
- `skills/trim/SKILL.md` is a Codex-native translation, not a copy, and it must stay in
  step with the command.
- Update `docs/features/trim.md` in the same change — a flag or capability change that
  leaves the feature doc behind is the drift
  [Adding a command](../specs/adding-a-command.md) forbids, and any doc touched gets
  `dirty: true`.

## Done when

- [ ] The verb answers the four deterministic gates and reports the residual two as `unknown`.
- [ ] It imports `timeline()` and friends from `src/hooks/lib/` rather than reimplementing them.
- [ ] It is registered in `cli.mjs`'s `VERBS`.
- [ ] `src/commands/trim.md` declares `Bash(my-command-tools:*)`, `commands/` is
      regenerated, and the Codex skill and feature doc are updated.
- [ ] Tests under `node --test` cover each gate against a fixture transcript.
- [ ] `pnpm test`, `pnpm run check:toolkit`, `./scripts/check-commands.sh` and
      `okq --bundle docs validate` pass.
